# Datasets

The datasets used in this research are publicly available and can be downloaded from the following repositories.

## English Movie Scripts Dataset

A curated collection of English movie scripts with verified age ratings.

* **Zenodo:** https://zenodo.org/records/20763133
* **Kaggle:** https://www.kaggle.com/datasets/pratik2kcn/movie-scripts-with-age-ratings-pratik-kalamkar-en

---

## Hindi Movie Scripts Dataset

A curated collection of Hindi movie scripts with verified age ratings.

* **Zenodo:** https://zenodo.org/records/20764389
* **Kaggle:** https://www.kaggle.com/datasets/pratik2kcn/movie-scripts-with-age-ratings-pratik-kalamkar-hi

---

## Marathi Movie Scripts Dataset

A curated collection of Marathi movie scripts with verified age ratings.

* **Zenodo:** https://zenodo.org/records/20764834
* **Kaggle:** https://www.kaggle.com/datasets/pratik2kcn/movie-scripts-with-age-ratings-pratik-kalamkar-mr

---
